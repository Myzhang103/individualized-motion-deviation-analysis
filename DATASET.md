# Dataset note

This project uses the **MUVIM (Multi Visual Modality Fall Detection Dataset)** for research.
The original dataset is not redistributed in this repository. Access is managed by the dataset authors and requires a data-access request / privacy waiver.

Repository contents are limited to analysis code and small, de-identified aggregate outputs produced during the research.
Frame images, videos, and frame-level pose-coordinate CSV files are intentionally excluded.

Reference:
- Denkovski, S. et al. (2022), *Multi Visual Modality Fall Detection Dataset*, IEEE Access, 10, 106422-106435.
- Official repository: https://github.com/MUVIM/FallDetection
